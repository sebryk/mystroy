# Древовидная таблица

Пример на Vue 3 и AG Grid.

## Установка и запуск

```bash
npm ci
npm run dev
```

Откройте http://localhost:5173.

## Другие команды

```bash
npm run typecheck   # проверка типов
npm run test        # тесты
npm run benchmark   # бенчмарки
npm run build       # сборка
npm run preview     # просмотр собранного проекта
```

Перед `preview` выполните `npm run build`.
